# Incremental AST evaluator replay update

Frozen before final labels on 2026-09-17. The initial AST specialist was trained on 48 inspected AST tasks and passed one 48-task AST-only transfer but failed a second 48-task mixed-stream transfer. Both transfer sets are now inspected source feedback. Train one new checkpoint from that specialist using the 96 verified tasks together, without reference/family labels as features. Each task contributes one listwise loss when its cap-512 pool contains both correct and incorrect candidates. Freeze normalization and architecture, train 40 epochs with AdamW learning rate 0.0001, weight decay 0.001, and listwise temperature 0.25. No target labels enter training.

Test on two independently seeded target streams: six eight-task AST-only banks (seeds 902306–902311) and six mixed-mechanism banks (seeds 902300–902305) from which the eight AST tasks per bank are evaluated. The mixed simulator stream is generated in full before selecting its AST cases so its RNG path matches the previous failed mixed test. Each task has one visible example and 23 host-held examples. V67/V73 produce candidates at cap 512 per source; all models see the same pool. Final correctness uses the last 15 host-held examples, with zero inference oracle queries.

Controls: frozen parent temperature-0.25 evaluator and the frozen first AST specialist. Primary endpoint is updated-minus-first-specialist correct top selections, reported separately by stream and as 12 paired bank differences with an exact bank bootstrap 95% interval. A supported improvement requires positive gains on at least five of twelve banks, a positive pooled interval, and no aggregate loss on either stream. Source acquisition cost is the 49,000 or so candidate labels from the two prior transfer banks, charged separately from the parent's and first specialist's earlier labels. Report exact source count, target reachability, selected counts, candidate count, model hashes and compute.

Freeze target tasks, pools, model hashes and choices before final labels. Regenerate the tasks and pools, replay all choices and oracle outcomes in a separate audit. This is a researcher-specified feedback update to an evaluator. A positive result would still leave the separate improver-growth and child-improver tests open.
