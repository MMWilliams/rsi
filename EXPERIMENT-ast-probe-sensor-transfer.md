# Matched-query AST output sensor transfer

Frozen before final labels on 2026-09-18. New mixed-stream seeds 902318–902323 generate full 48-task mixed banks, from which eight AST tasks per bank are evaluated. New AST-only seeds 902324–902329 generate eight AST tasks per bank. Each task has one public example, eight host-held probe inputs whose true outputs are initially sealed, and 15 further host-held final examples. V67/V73 produce candidates at cap 512 per source. The replay-updated AST ranker is fixed by model hash and sees the same candidate pool under every sensor policy.

The ranker and candidate predictions on eight probe inputs are computed without true probe outputs. Freeze all candidate pools, rank scores, predicted output matrices, first-query choices, model hash and policy code before opening any probe or final outputs. A second query may depend only on the first revealed output and the frozen policy. Each query returns one exact oracle output for the chosen input; all candidate evaluations for predicting outputs are local compute and are reported separately from oracle calls.

At **one query per task** compare random, full-pool minimax and top-20 entropy. At **two queries per task** compare random, full-pool minimax, top-20 entropy, top disagreement and weighted entropy, each recomputing its second query after the first output. Also report zero-query ranker and candidate reachability. Every one-query arm spends exactly 96 oracle outputs; every two-query arm spends exactly 192. The primary sensor edit is top-20 entropy versus minimax at one query on identical tasks and pools. Require at least seven positive paired banks and a positive exact bank-bootstrap 95% interval for a stronger sensor claim. The two-query comparison is exploratory unless one method beats the strongest same-budget fixed control with the same gate. Report both generation streams separately.

Score final correctness on the last 15 examples. Regenerate tasks, candidate pools, predicted probe outputs, model ranks and all outcomes in an independent audit. A within-task query gain is useful evaluator feedback at extra cost; it is not retained evaluator intelligence or improver growth. The next improver study must decide where to spend output queries and whether to install a sensor under a matched total budget, then test child-improver transfer.
