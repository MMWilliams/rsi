# Fixed-total-budget AST query allocation transfer

Frozen before final labels on 2026-09-18. Source feedback is the audited 96-task AST output-sensor transfer. A 12-feature ridge model predicts the incremental task utility of the first and second top-20 entropy output queries from public examples, frozen rank scores and predicted candidate outputs. Leave-one-bank-out development selected ridge penalty 100 on a 37/96 versus 36/96 one-per-task edge; this is development evidence only. The final weights and normalization are saved in `analysis/ast-query-allocation-development.json`.

Fresh mixed-stream seeds 902330–902335 generate full 48-task mixed banks and select the eight AST tasks per bank. Fresh AST-only seeds 902336–902341 each generate eight AST tasks. One visible example, eight initially unlabeled probe inputs and 15 final examples per task; V67/V73 cap 512. Every arm uses the same replay AST ranker and the same top-20 entropy probe policy when it buys a query.

Each eight-task bank has **exactly eight oracle output calls** per allocator arm. An exact multiple-choice knapsack chooses 0, 1 or 2 calls per task from predicted marginal values, with no task receiving more than two. Compare learned allocation with one query on every task, deterministic random two-on-four, fixed high entropy two-on-four, fixed high top-disagreement two-on-four, and a within-bank feature-scrambled learned state of the same size. All allocations, candidate pools, model and policy hashes, predicted outputs, rank scores and first-probe choices are frozen before true probe outputs or final labels. Second probe choices may depend on first outputs under the fixed sensor policy.

Primary endpoint: learned minus the strongest fixed allocation at 96 total oracle outputs over twelve banks. Require at least eight positive paired banks and an exact bank-resampling 95% interval lower bound above zero. Also compare learned with scrambled state and report by stream, reachability, no-query score, candidate execution, acquisition labels, and all query costs. Reconstruct tasks, pools, predictions, allocations and outcomes in a separate audit. A better allocation would support a scoped feedback-trained evaluator decision; a later-parent-to-better-child-improver test remains separate.
