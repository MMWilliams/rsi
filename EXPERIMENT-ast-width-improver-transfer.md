# Four-slot AST search edit plus replay ranker and exact output sensor

Pre-label implementation amendment: the first source-only freeze at `runs/ast-width-improver-transfer-20260918/` was aborted while preparing admission because a width-control constant shadowed the temperature-route mapping and raised `IndexError`. No admission stage files or oracle labels were written. The constant was renamed, and the experiment restarts as `runs/ast-width-improver-transfer-20260918-v2/` with new source, runner and protocol hashes; all seeds and gates below remain unchanged.

Frozen before opening seeds 902468-902485. This is a **cross-component package** test on the six-mechanism mixed task stream. The common zero-query non-AST route, AST replay ranker, top-20 entropy first probe and external exact interpreter are fixed. Each 48-task bank contains eight AST tasks. A width policy chooses exactly **four** AST tasks to expand from the 128-per-source base pool to the 512-per-source wide pool, using **only base-pool public features**. Every AST task then receives one true output query on its selected pool: exactly eight query calls per bank for every active policy. Thus selection methods have the same width-slot and query-call budgets. The generated candidate count varies with deduplication and is reported separately. Base-only and full-wide arms have different search budgets and are diagnostic controls.

Source development used 18 opened mixed banks, 144 AST tasks. The fixed low-score-gap four-slot heuristic scored 42 AST choices under whole-bank source validation versus deterministic random four at 38; a separately opened twelve-bank validation scored 20 versus 16, with a -1 to +9 paired interval. Those labels are development only. The trainable improver uses base-pool features and ridge penalty 10, the strongest source-validated ridge method. The initial parent trains on the 144 opened AST effects; the later parent inherits 96 further opened AST effects. Scrambled-label and duplicate-old-row parents are same-row-count controls. Fixed low-gap, high-entropy and deterministic random width rules are controls. No target label or wide-pool prediction is allowed into the width decision.

Six 48-task admission banks use seeds 902468-902473. The protected gate admits later-parent deployment only if it beats deterministic random four by at least two total correct choices, wins at least four of six banks, loses no more than one, and is at least as correct as the initial parent. Raw children are still tested if the gate rejects; the protected policy falls back to the strongest fixed four-slot heuristic selected from *source development* (low gap), not an admission-tuned control.

Children use the same ridge-10 learning rule and the same 48 new AST effects. Freeze children, frozen parents and controls. Primary recursive gate: the protected admission gate accepts; later child beats initial child on at least eight of twelve paired banks with an exact bank-bootstrap 95% total-difference lower bound above zero; it beats its frozen parent, scrambled and duplicate children, and the fixed low-gap/random four-slot controls at the same budgets. Separate fixed-component gate: low-gap four beats random four on at least eight banks with positive interval lower bound and no more than two losing banks. Compare full-wide and base-only arms separately because they do not share the width budget. A result on AST-only output allocation does not replace the stronger cross-family eight-call query allocator; this study isolates the search-width choice within a fixed search/ranker/sensor package.
