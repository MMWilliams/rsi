# Frozen E1 versus E0 ranker-plus-query package transfer

Frozen 2026-09-18 before generating seeds 902558-902569. On four opened, fully audited panels, 48-bank leave-one-bank-out source scoring of the same 24-feature mechanism-interaction query rule gave E1 ranker plus matched query model 1,517 correct versus E0 plus matched query model 1,488 at eight output calls per bank, paired interval +10 to +48. This is development, not a fresh package result. `combined_ranker_query_development.py` and its result are frozen by hash.

Generate twelve new 48-task mixed banks on the same synthetic six-mechanism generator, with identical candidate pools, old public-block/AST route, predicted probe outputs and fixed top-20-entropy probe index. For each target task, E0 and E1 each rerank the same old top 20. The 24 public query features are recomputed relative to that ranker's order; no target oracle label or hidden output is used in model fitting or call selection. Both packages use eight exact output calls per bank. Freeze candidate orders, features, query models, forecasts and selected task IDs before scoring target final labels. The external interpreter checks final correctness.

The primary matched package comparison uses E0 and E1 cheap interaction query models each trained on the same 2,304 audited prior task effects from the four opened panels. Their target feature extraction, model class, candidate-prediction work and 96 output calls are matched. E1 candidate reranking itself used 288 additional historical candidate-training tasks compared with E0; charge those 5,666 labels separately. Also compare E1 and E0 with the old frozen allocator, and their zero-query scores.

For incremental feedback, E1 initial uses the first two source panels (1,152 task effects); E1 later uses all four (2,304). A scrambled control retains the first two and rotates the last two panels' gains within public mechanism. A duplicate control repeats the first two effects. They share E1 candidate order and 96 calls. Banks 902558-902563 are admission; 902564-902569 are protected transfer.

Promote the combined E1 package over matched E0 only if all-panel E1-minus-E0 gain is >=8, at least eight banks improve, no more than two lose, and the exact paired bank-bootstrap lower endpoint is positive. Report final correctness, no-query reachability, selected query gain, forecast MSE, all bank differences, output calls, candidate rescoring and source acquisition. The later E1 feedback child passes admission only if it matches or exceeds E1 initial and E1 with the old allocator on the first six banks. A separate child-growth claim requires later-minus-initial protected gain >=4, at least four positive banks, positive lower endpoint, and later ahead of scrambled, duplicate and old-allocator controls. Preserve the earlier checkpoint if its update fails.

This tests fixed researcher-authored components on one synthetic task contract. A package gain does not show that a later improver reliably produces stronger children or expands its own edit vocabulary.
