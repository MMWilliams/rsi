# Common-bank cross-component evaluator edit transfer

Frozen before new bank labels on 2026-09-18. Development replay on the already inspected full mixed banks showed that applying temperature 0.25 globally scored 137/288 versus the public-block fixed temperature map at 140, with the three losses concentrated in transformation. The fixed AST replay ranker and one-query sensor gave separate gains. These inspected results select the edit catalog, not the answer on new banks.

Generate six fresh 48-task banks, seeds 902402–902407, with eight tasks in each of six synthetic mechanisms. All policies share each task's visible example and the same candidate pools: base V67/V73 or family-specific source pairs at cap 128, plus V67/V73 cap 512 for AST. Final correctness uses fifteen held-out examples. The true output oracle is outside all model/edit write paths. For AST, eight probe inputs are available; exact predicted outputs for every candidate are frozen before true outputs.

## Catalog and budgets

At zero output calls compare: public-block fixed temperature map; global temperature 0.25; fixed map plus wide AST replay ranker; global sharp temperature plus AST ranker. The global edit differs from the map only where the map uses temperature 0.5 (public blocks 0x700 and 0xD00). Every arm uses identical candidate pools, so this isolates evaluator choice from reachability.

At **eight calls per 48-task bank**, use the wide AST ranker and spend all calls on the eight AST tasks. Compare one top-20 entropy query per AST task, one minimax query per task, and the prior frozen sequential conditional allocator. Cross each with fixed-map or global-sharp non-AST choices. The adaptive allocator is a **shadow research arm** because its earlier protected admission gate rejected it. It may see a true output only after buying that query. All arms have exactly 48 logical calls over the six banks; candidate generation/training costs are reported separately. AST cap, ranker, query sensor, global loss edit and their combinations have task-level and bank-level effect rows for a later edit-policy experiment. Rollback corresponds to keeping the fixed map and fixed one-query control.

Primary integration endpoint: fixed-map plus AST ranker and one top-20 query versus fixed map at zero calls, reporting the query cost rather than treating unlike budgets as free. Same-budget edit endpoints: global-sharp minus fixed-map routing with the same AST sensor; adaptive minus top-20 and minimax with the same non-AST choices. Require five of six positive paired banks and an exact bank-bootstrap 95% interval lower bound above zero to promote a learned or global edit. AST ranker, generator reachability and output-query effects are reported separately. Negative task effects, especially transformation, are retained in the balanced edit-effect table.

Freeze tasks, pools, model/code hashes, rank scores, static selections, candidate-predicted probe outputs and first-probe choices before revealing true outputs/final labels. The adaptive algorithm and model are frozen; its actual action trace is logged as outputs are purchased. An independent audit must regenerate all 288 tasks, pools, predictions and decisions, replay the adaptive action trace and re-evaluate candidate labels. This experiment tests cross-component compatibility and supplies balanced effects; it does **not** alone prove a later improver creates a better child.
