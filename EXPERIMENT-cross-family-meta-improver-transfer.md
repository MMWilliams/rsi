# Protected cross-family evaluator-edit improver transfer

Frozen before new admission and transfer labels on 2026-09-18. The base generator, public-block ranker route, eight probe inputs, top-20 entropy probe selector and eight-call bank budget are fixed. The bounded improver can edit only the **query-value evaluator training rule**: family-frequency, basic ridge-10, family ridge-10/100, or interaction ridge-10/100. It chooses a rule by leave-one-bank-out verified source correctness under the same eight-call budget; catalog order breaks ties. The external oracle supplies task effects and final correctness, outside the improver's write access.

Initial parent P0 learned from 576 inspected one-query task effects and selected interaction ridge-100 (source CV 342/576). Later parent P1 inherited 288 more balanced task effects and selected interaction ridge-10 (source CV 526/864 versus ridge-100 524). A same-size scrambled-label P1 control selected ridge-100; a duplicate-old-data control selected ridge-10. These states and all source hashes are frozen before new tasks. P1 has 288 more historical query outputs plus final correctness/candidate costs; equal *new* feedback does not mean equal total acquisition.

## Prospective sequence

1. Six fresh 48-task mixed **admission** banks, seeds 902420–902425. Freeze each parent's eight selected task IDs before opening outputs or final labels. Evaluate all one-query task effects for common child training: 288 shared oracle output calls and external final correctness labels. A protected admission gate accepts later-parent deployment only if P1 beats the prior strongest fixed transformation/mutation schedule by at least three correct tasks overall, wins at least four of six banks, and loses no more than one. Raw children are still tested if the gate rejects.
2. Each parent uses the identical training-rule selection algorithm on its own historical table plus the same 288 admission rows, producing a child improver and trained allocator. Freeze child states and method choices. Include scrambled and duplicated-history children, fixed ridge-10/100 trained on P1's table, and the two frozen parents as controls.
3. Twelve untouched 48-task mixed **transfer** banks in two six-bank panels: 902426–902431 and 902432–902437. Freeze both panels' tasks, pools, candidate-output predictions, rank scores, feature vectors and eight-call allocations for all policies before scoring either. Every deployed arm uses 96 logical true output calls across the twelve banks. Compare selected programs on fifteen disjoint final examples. Score all zero/one task outcomes only after the allocations are frozen.

Primary recursive endpoint: later child P1 minus initial child P0 correct program choices on the transfer banks. Require at least eight positive paired banks, exact bank-bootstrap 95% interval lower bound above zero, later child better than its own parent on the same frozen transfer pools, admission gate acceptance, higher score than strongest fixed schedule and scrambled/duplicated children, and **at least** the best fixed ridge-10/100 training-rule control fitted to P1's same data. A selected rule can be identical to one such control, so a tie is expected in that case; report the fixed-rule comparison separately rather than crediting the selector for a tie. Report every policy's by-bank outcomes, query-gain calibration, reachability, candidate executions/predicted outputs, source and new acquisition, training fits and wall time. A pass would support **bounded training-rule improver growth** on this synthetic distribution. It would not show self-generated edit types or general RSI.

The independent audit must retrain all parent and child states, reconstruct the admission gate, regenerate all tasks/pools/predictions and choices, and re-evaluate candidate labels. The benchmark's host family tag is not an evaluator input: the improver uses the Unicode block computed from visible task text; prior source and transfer blocks mapped one-to-one to mechanism in the public-feature audit.
