# Fixed-total cross-family output-query evaluator transfer

Frozen before new labels on 2026-09-18. On two already inspected six-mechanism panels (576 tasks), one top-20 entropy output query improved 127 task choices and harmed none. At eight calls per 48-task bank, AST-only scored 315/576, transformation-only 330, and a leave-one-bank-out ridge model with mechanism interactions and penalty 100 scored 342. This development result selected the model, not its fresh-bank outcome.

Freeze the ridge-100 model on all 576 verified task effects. Features are public family/Unicode block, frozen candidate rank scores and candidate-predicted outputs on eight probe inputs. The model predicts the correctness gain of one output query per task and chooses the eight highest values in each 48-task mixed bank. It cannot read true outputs or final correctness before the eight IDs are frozen. One query uses the same top-20 entropy probe selector for every policy. The generator/ranker is the public-block fixed temperature map for five mechanisms and the widened V67/V73 replay AST ranker for AST. Candidate pools and top choices are common across arms.

Test twelve untouched 48-task banks in two separately replayed six-bank panels: seeds 902408–902413 and 902414–902419. Each arm spends exactly eight true oracle output calls per bank, **96 total**. Controls: AST-only, transformation-only, mutation-only, a four/four transformation-mutation split, family-balanced, deterministic random, family-frequency value, basic ridge-10, family ridge-10 and interaction ridge-10. The last four are development competitors, not candidates to select after final labels. No-query and one-query-on-all-task scores are diagnostic cost endpoints; oracle-hindsight allocation is reported only as unreachable headroom.

Primary endpoint: interaction ridge-100 minus the strongest fixed 96-call control on paired banks. Require at least eight positive bank differences, an exact bank-bootstrap 95% interval lower bound above zero, and no aggregate regression in either six-bank panel. Report also gains/harm by mechanism, candidate reachability, query placements, source acquisition (576 prior query effects plus final correctness labels), candidate-output prediction cells, generation/execution time and final candidate-label checks. Equal oracle calls do not imply equal inference compute because the learned policy predicts outputs for every task.

For each panel, freeze tasks, both cap levels of candidate pools, model/code hashes, rank scores, first probes, feature vectors, and all eight-call allocations before opening true outputs/final labels. An independent audit regenerates candidate pools and outputs, reconstructs model weights, selections, outcomes and budgets. A positive result is scoped feedback-trained **evaluator allocation** growth. It is not yet a later-parent-to-better-child improver result.
