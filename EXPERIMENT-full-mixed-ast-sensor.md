# Full mixed-system AST sensor integration

Frozen before final labels on 2026-09-18. Six new seeds 902342–902347 generate 48-task banks with eight tasks from each of six synthetic mechanisms. Each task has one public example, eight sealed probe inputs/outputs, and 15 final examples. Candidate sources follow the archived family-source map at cap 128; AST alone uses V67/V73 cap 512. The prior fixed public-block temperature map handles the five non-AST mechanisms and is the zero-query control. The replay AST ranker and source-trained query allocator are fixed by hashes.

For the eight AST tasks per bank, compare one top-20 entropy query each, one minimax query each, one deterministic random query each, learned zero/one/two allocation, and random two-on-four allocation. **Every budgeted arm spends exactly eight oracle output calls per bank**, 48 total. Non-AST choices and candidate pools are identical across arms. Also report the zero-query fixed map, the map with the AST ranker but no query, and a two-query-per-AST curve at 16 calls per bank. Query methods predict candidate outputs on the eight probe inputs locally, freeze first-query choices before seeing true outputs, then filter matching candidates and rerank. A second query may depend only on the first revealed output under frozen code.

Primary system endpoint is top-20 one-query map minus the zero-query fixed map, with query cost attached; require positive gains in all six banks and a positive exact bank-resampling interval to call it a reliable budgeted system gain. Query-policy superiority is a separate same-budget endpoint: require at least five positive banks and a positive interval against the strongest other fixed eight-call control. The learned allocator must beat the strongest fixed eight-call policy under that same gate before it is considered an improver component. Report reachability, AST and non-AST scores, candidate counts, oracle calls and acquisition costs separately.

Freeze tasks, pools, public predicted outputs, model hashes, rank scores, first probes and learned/fixed allocations before true probe outputs or final labels are opened. Replay task and pool generation, predictions, allocations and outcomes in an audit. The simulator's family tag chooses candidate source pairs as in prior studies; evaluator routing uses public Unicode block only. This is a synthetic benchmark integration, not general intelligence or recursive improver growth.
