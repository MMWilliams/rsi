# Frozen post-query evaluator transfer

Frozen 2026-09-18 before generating seeds 903100-903123. Twenty-four shifted-AST banks contain eight tasks each, with one visible example and 23 hidden examples. The candidate generator, old AST replay ranker, E0 top-20 reranker, old-top-20-entropy probe, and cheap four-call allocator are fixed. The new post-query sensor-conditioned model and matched plain-feature model are the joblib files produced by `post_query_candidate_development.py` from 1,152 opened source tasks and 8,681 verified surviving-candidate labels. No task or final correctness label from the new banks enters model fitting or selection.

For each task, generate the widened pool and rank it before revealing the output at the fixed probe. The external interpreter provides that one probe output. The three candidate policies then select from programs consistent with that output: existing E0 order, the plain-feature post-query model, and the sensor-conditioned post-query model. Both trained post-query models choose only among the old top 20 that survived. The current E0 order can choose from the full pool. Freeze all three choices, probe outputs, pool hashes, and the cheap allocator's four call locations per bank before final labels are scored. Without a call, all policies share E0's first choice.

Primary evaluator endpoint: final correctness after one fixed output call on every task, at equal pools, calls and candidate-scoring opportunity. Compare sensor versus E0 and sensor versus matched plain-feature model on 24 paired banks. A promoted post-query evaluator requires sensor minus E0 at least +6/192, positive gains on at least 16/24 banks, and a positive paired bank-resampling interval lower endpoint. The sensor-specific feature claim additionally requires a positive interval versus plain. Four-call outcomes with identical call locations are the deployable budgeted endpoint; report them separately and do not promote the integrated seed if that gain is uncertain or negative. Record full-pool/top-20 reachability and label, prediction, call, model inference and candidate-generation costs.

Regenerate tasks and candidate pools, recompute predictions, frozen decisions, probe outputs and final correctness labels independently. This is an evaluator transfer test on a new instance panel from the same shifted-AST generator, not a withheld-mechanism result or a recursive child-improver test.
