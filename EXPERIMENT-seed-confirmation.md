# Seed confirmation and feedback-controller transfer

Declare before source-search outcomes or confirmation task generation. Use the source-search seed chosen by the frozen admission rule. Keep all source candidates and failures in the record.

Confirmation episode banks: bootstrap seed 206001 (six tasks), feedback reservoir 206002 (48 tasks), admission 206003 (18 tasks), mixed final 206004 (24 tasks), AST final 206005 (12 tasks), changed-arithmetic final 206006 (12 tasks). All use independently randomized visible examples (eight public and sixteen host-only), with sixteen candidates per source. Changed-arithmetic tasks use the four predeclared parameter sets in `seed_casebanks.py`. Report panels separately. No task is selected, discarded, or resampled according to outcomes.

Test every fixed acquisition tactic with the source-selected evaluator and integration gate. Compare to transferable controller knowledge at source rounds 0, 2, and 4; a controller with shuffled rewards; and a round-4 controller that updates its effect table online using admission feedback. All begin with the same bootstrap evaluator and reservoir, buy four task label sets per round for four rounds, and use the same integration rule. The later controller predicts tactic utility from public evaluator state and its recorded source effects, not final outcomes. Source selection cost is charged separately; candidate-level oracle executions remain explicit.

Feedback actively follows the retained evaluator checkpoint. After querying a batch, fit a candidate evaluator on cumulative feedback. Accept it only through the source-selected gate on the separate admission bank. Rejected checkpoints do not drive subsequent acquisition. This distinguishes actual integration from replaying a gate over an already fixed learning trajectory.

At each checkpoint freeze predictions for all five evaluator components on identical final pools. Also record the deployed driver choices with a fixed 0.05 score margin over the frozen-base candidate. Measure evaluator correctness, deployment correctness, probability error, regressions and cost. Keep the initial evaluator, frozen base and best source-selected static tactic as controls. Source-round-2 and source-round-4 controllers are tested from the same base; all state and label access is journaled.

Before opening any final label, freeze all arms, checkpoint states, proposals, update decisions and selected programs. No final-bank outcome may select a controller, checkpoint, gate or margin. Rank any unexpected final winner as exploratory only. Compare inherited, empty and scrambled controller knowledge. A genuine positive feedback result requires improved held-out evaluator utility and improved integrated decisions through accepted updates; gains must not depend on inspecting the final bank. One confirmation episode remains provisional until independent replication.
