# Frozen shifted-AST seed transfer

Frozen 2026-09-18 before generating seeds 903000-903011. This is a changed-mechanism stress test, not a new tuning set. The 12 banks each contain eight `shifted_ast_bank` tasks with one visible and 23 hidden input/output examples. Their characters occupy the known AST Unicode block, but the held-out predicates use four arithmetic rules not drawn from the source `ast_transition` generator.

The public candidate generator receives each task's visible example and ID and is routed through the existing AST V67/V73 arms with the same base cap 128 and widened cap 512. The old AST replay ranker and the frozen E0 top-20 candidate reranker score the same widened pool. No shifted-AST outcome is used to retrain them. A fixed old-top-20-entropy probe is chosen before hidden outputs are opened. Save tasks, pools, candidate orders, predicted outputs, features and four-call selections before final scoring.

Compare: old versus E0 without calls; E0 with four exact output calls per eight-task bank placed by the protected cheap 24-feature model trained on 1,152 prior known-family query effects; E0 with four calls selected by the previous frozen allocator; E0 with four deterministic hash-selected calls; and E0 with one call on all eight tasks as a separate double-call-budget reference. All four-call policies use the same E0 order, candidate/output predictions and probe; only call locations differ. The exact external interpreter supplies the first eight probe outputs and checks candidate correctness on the final 15 hidden examples.

Primary outcomes are full-pool and old-top-20 reachability, zero-call correctness, selected query gain, final correctness and exact call counts. Report all 12 bank differences and paired exact bank-bootstrap intervals. A claim that the learned allocator transfers requires at least +4 correct choices over both old-allocator and hash-four controls, at least eight positive banks versus each, and positive lower interval endpoints. If reachability is too low to permit four extra choices, classify the result as a generator/action-space limit rather than an evaluator promotion failure. Independently regenerate tasks, pools, output predictions, frozen decisions and final oracle labels. Include candidate generation, model inference, prediction cells and calls in the cost vector.

This test does not retrain the improver or prove a positive recursive loop. It checks whether the current supported seed has any coverage and feedback value on a changed mechanism with a familiar public cue.
