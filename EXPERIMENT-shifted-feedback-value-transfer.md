# Frozen shifted-feedback query-value transfer

Frozen 2026-09-18 before generating seeds 903200-903223. Twenty-four eight-task shifted-AST banks use one visible and 23 hidden examples. All policies use the same V67/V73 widened pool, old AST replay ranker, E0 top-20 reranker, fixed old-top-20-entropy probe, and exact external output sensor. The no-query choice is E0's first candidate. One queried task consumes one exact-output call and is checked on the final 15 hidden examples. Candidate generation, probe choice, model forecasts, four-call locations and post-query candidate choices are frozen before final correctness labels open.

Primary question: does adding verified changed-arithmetic query effects improve *where the evaluator buys feedback*? Compare the protected cheap 24-feature E0 allocator with a pooled interaction-ridge model that trains on 1,152 familiar query-effect records plus 96 shifted-AST records, with the shifted records repeated 12 times in the fit. Both use the same 24 deployment features, E0 candidate order and **four calls per eight-task bank**. Additional acquisition is 96 shifted task effects for the pooled model, charged separately. The update rule and weight were selected from opened development, so this new panel is the first transfer test of that choice.

Controls use the same four-call budget: familiar-only prior model, deterministic hash-four, pooled update with shifted labels scrambled across tasks, and pooled update replacing shifted rows with 96 duplicated familiar rows. A shifted-only ridge-100 model tests whether the familiar data should be removed. A secondary joint action policy may choose among E0, plain top-50 survivor and sensor-conditioned top-50 survivor rankers after a call, using the same public value forecasts to place calls. These candidate models were trained on 19,789 verified survivors from earlier panels and are fixed. Their extra candidate scoring is charged separately. Report no-call, one-call-each, exact four-call outcomes, full-pool/top-20 reachability, bank differences and exact paired bank-resampling intervals.

Promote the pooled E0 query-value edit only if it exceeds cheap E0 by at least six correct tasks of 192, wins at least eight of 24 banks, has a positive interval lower endpoint, and exceeds both scrambled and duplicated controls with positive interval lower endpoints. Promote the joint action package only if it separately beats the best E0-only four-call policy by at least six tasks, wins at least eight banks and has a positive lower endpoint. An opened-panel gain or an oracle hindsight ceiling is not a promotion result. Independently regenerate tasks, pools, predictions, frozen decisions, probe outputs and all final candidate labels. This evaluates an incremental feedback-trained evaluator; recursive improver growth still requires later-parent-to-better-child transfer from the same base under matched acquisition and inference costs.
