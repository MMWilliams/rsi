# Frozen shifted-survivor evaluator transfer

Frozen 2026-09-18 before generating seeds 903300-903323. Twenty-four eight-task shifted-AST banks use one visible and 23 hidden examples. All policies share the existing V67/V73 widened candidate pool, old AST replay ranker, E0 top-20 reranker, old-top-20-entropy probe and the protected cheap four-call locations per bank. The no-call choice is always E0. A queried task receives the one exact external probe output; candidate policies may then rank consistent programs. Freeze tasks, pools, output predictions, probe outputs, all candidate choices and call locations before final correctness labels open.

Primary component test: a plain-feature top-100 survivor ranker trained on **96 prior shifted tasks** (about 1,527 verified survivor labels) versus E0 and the familiar-trained plain top-50 survivor ranker, each at the same 96 output calls and identical pools. The top-100 model incurs more candidate-feature and model scoring and this cost is reported. A scoped evaluator promotion requires at least +10/192 over both baselines, at least 12 positive banks versus each, and positive paired bank-resampling lower endpoints. Also report one-call-each outcomes as a separate 192-call reference. This is same shifted-generator instance transfer, not withheld-rule-family transfer.

Incremental feedback test: the same top-100 plain model class, architecture and fitting rule trained on the original 96 plus **192 additional shifted tasks** (about 4,862 verified survivor labels total) versus the 96-task checkpoint. Controls add task-wise label-scrambled extra examples or duplicate the first source panel to match nominal task count without new information. A claim that the extra verified feedback improved the evaluator requires at least +4/192 over the 96-task checkpoint, at least eight winning banks, a positive interval lower endpoint, and positive lower endpoints versus both controls. A sensor-feature top-100 model trained on the full 288 tasks is a secondary matched-label feature comparison; it must beat the plain model at equal calls and source labels before a feature-specific claim.

Independently regenerate the source labels and model weights, all target tasks and pools, probe predictions, frozen candidate choices and final correctness labels. Report source acquisition, candidate generation, top-20/top-50/top-100 scoring, output-call and oracle-label costs separately. This test can demonstrate feedback-trained evaluator growth; it does not demonstrate recursive improver growth unless a later improver uses that learning to produce a stronger child improver from the same base and budget on another untouched bank.
