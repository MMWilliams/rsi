# Frozen specialist applicability transfer

Frozen 2026-09-18 before generating 24 new mixed AST banks, seeds 903400-903423. Each bank has four familiar `ast_transition` tasks and four `shifted_ast` tasks, one visible and 23 hidden examples each. Both task types are routed through the same V67/V73 widened AST generator, old replay ranker, E0 top-20 reranker and fixed entropy probe. The protected cheap query allocator buys exactly four external output calls per bank (96 in total). All candidate policies see the same pools, call locations and probe output; unqueried tasks use E0's zero-call choice. The true task type is retained only by the external scorer for subgroup analysis. Neither router receives family, generator name, reference, seed or task ID as a predictive feature.

The specialist is the previously frozen 96-task shifted plain top-100 survivor model. A paired-effect router is trained from 192 familiar AST tasks on the first two audited panels plus 192 shifted tasks on the second shifted panel; the specialist itself was trained on the earlier disjoint 96 shifted tasks. Router inputs after a purchased call are two observed input/output pairs (one original visible pair and the exact probe result), candidate-score and survivor statistics, and the identities of the two candidate choices only through their numerical ranks and predictions. Fit a fixed shallow boosted regressor to the verified specialist-minus-E0 correctness effect. The primary rule accepts the specialist only when predicted gain exceeds **0.15**, selected on opened development; a zero-threshold route is a secondary ablation. A task-type classifier trained from the same public examples is a fixed-context control, not the primary route. A task-wise shuffled-effect model tests inherited-effect information. Compare E0-only, specialist-only, each router, and the unavailable true-type route under the same calls; the latter is an oracle upper bound, not a deployable policy.

Primary integration gate: at 96 calls the conservative effect router must gain at least +8 correct tasks over E0, beat specialist-only by at least +4, have positive paired bank-resampling lower endpoints versus both, and win at least 10/24 banks versus E0. On the familiar subset it must have no net harm versus E0, at most one losing bank, and a subgroup interval lower endpoint at least zero. On the shifted subset it must retain at least +8 correct choices over E0. The scrambled-effect router must not match the primary gain. Report one-query-each outcomes separately as a 192-call reference, as well as reachability, source-label acquisition, candidate/prediction cost and any family-specific negative transfer.

Freeze tasks, pools, predicted outputs, source model hashes, router models, router forecasts, candidate choices and 96 call locations before final hidden-example correctness labels open. Independently regenerate source paired effects and target decisions and re-evaluate all final candidate labels. This is a test of a researcher-designed applicability improver edit. Even if it passes, recursive improver growth still requires a later parent to produce a stronger child improver from the same starting state and budget on another untouched bank.
