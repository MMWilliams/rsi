# RSI pilot v2 — calibration fixes declared before fresh holdout evaluation

The first engineering pilot revealed an uninformative inheritance assay: all restart conditions accepted zero edits when each decision saw only two development tasks and two admission tasks. The raw Qwen3-0.6B also supplied no verified self-training rows in its first round. These failures motivate the following changes. Keep all v1 artifacts and its original source snapshot.

Use fresh bank seed 9162602. Double development/admission source batches, use 96 transfer-development tasks split equally between edit evaluation and admission, and allow four proposals per generation in the transfer test. Every compared condition gets exactly the same opportunities and fresh tasks. No threshold is loosened and no positive result is required.

Bootstrap all neural arms equally from the same oracle-verified search trajectories on the first 64 training tasks, using 32 LoRA steps. Copy the resulting adapter tensors into the three independent arms. Measure baseline pass@k after this shared initialization. Exclude these 64 tasks from subsequent neural rounds. This tests self-training after a common grammar/solver initialization, similar in purpose to the published study's trained generation-0 model, but remains a different experiment and model size.

Record each operator's positive development effects separately from its admission count. The table's sampling estimate should not treat a positive candidate that lost to another candidate as a failed trial. Admission and descendant metrics remain distinct. This is a measurement correction, not a new source of labels.

All remaining principles in EXPERIMENT.md apply: independent execution oracle, bounded edit interface, replay before hidden scoring, disjoint task/template banks, paired controls, raw pass@k through 64, one neural training seed, and explicit non-matching total compute. In the adaptive neural arm, each round first generates cached proposals with its current adapter and uses them during three meta-edit generations, then harvests verified training solutions and distills them. The next round's edited search therefore sees proposals from the updated model. Its configuration and effect table persist between rounds. The CPU inheritance assay separately holds the model-free symbolic substrate fixed to isolate table effects. Neither component implies demonstrated recursive compounding.

Primary pilot comparison: intact versus empty and scrambled effect tables after equal restart budgets. Secondary: final search accuracy and raw-model pass@k after two distillations. Report every outcome including null effects, failed operator proposals, and control arms with no valid training data. Larger neural seed counts, interleaved feedback, and compute-matched scientific claims remain future experiments.
