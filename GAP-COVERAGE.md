# Which research gaps this implementation tests

| Gap or flaw | Implemented response | What the pilot can establish |
| --- | --- | --- |
| A better artifact is mistaken for a better improver | Restart generation-0/3/6 effect tables from an identical search ancestor; compare after equal edit opportunities | Whether inherited selection knowledge helps this bounded improver on fresh tasks |
| Inheritance is confounded with more solved examples | Intact, empty, and scrambled tables share identical code, initial operator catalog, and macro library | A causal intervention on table contents, conditional on the tested task prior and budgets |
| Self-reported fitness can be manipulated | Host-owned independent AST oracle; recompute visible outputs; reject forged reports; keep hidden examples out of worker inputs | Resistance to the tested proposal-interface attacks, not a sandbox guarantee against arbitrary same-user native code |
| Replay is treated as proof of quality | Replay precedes separate execution sensors and hidden-example admission | Deterministic search behavior plus independent finite-test correctness |
| Search success is counted as model capability | Measure selected search accuracy and raw independent model pass@k separately | Whether verified distillation changes the sampled model curve through k=64 |
| Extra sampling is compared with an unequally weak baseline | Include a classical fixed searcher, random gated edits, fixed-search distillation, and verified self-training | Which components help at the declared limits; not a fully matched total-compute result |
| The model is too weak to supply self-training data | In v2, identical shared bootstrap from verified search trajectories before branching | A usable generation-0 comparison; initialization cost is recorded |
| The weights and amplifier never interact | Current adapter proposals enter three edit generations, then verified distillation changes the next round's proposals | A working system feedback loop; compounding requires a positive measured outcome |
| An inherited table records only winners | Positive measured effects are recorded independently of admission; rejected and losing proposals remain journaled | Reduced selection bias in the table; finite validation and state dependence still matter |
| The edit catalog is permanently fixed | Local Qwen proposes bounded arithmetic edit expressions; passing extensions face a removal ablation | Whether catalog extension helps inside this metalanguage; not unrestricted algorithm invention |
| A final holdout quietly becomes a training signal | Separate source, admission, final, transfer-development, and transfer-final banks; fixed query schedule | Scores not used in edit selection; repeated development feedback remains adaptive |
| Repeated tuning is hidden | Source/config/bank hashes, source snapshots, journals, preserved interrupted runs, and separate v1/v2 protocols | An auditable history of implementation fixes and experimental changes |
| Verified targets are mistaken for a beneficial weight update | v3 retention runner compares parent/candidate sampled coverage on separate validation tasks and verifies rollback | Measured finite-validation protection; it cannot guarantee population non-regression |
| Training silently discards older capabilities | Cumulative verified replay against fresh-only training on shared frozen trajectories | A controlled retention intervention, conditional on the dataset and update budget |
| A change has an explanation but no traceable evidence | Change register, row pools, per-step draws/losses, exact model lineage, raw validation/final outputs and independent audit | Reproducible observed effects with mechanistic hypotheses kept separate |

Remaining research requirements are a powered multi-seed neural study, matched total compute including bootstrap and meta-search, stronger transfer to another task distribution, and a larger or more expressive program domain. “Optimal” and “RSI achieved” are outcome claims; the existence of the machinery alone supports neither.

V4 update: balanced source calibration produced six trials per operator but
193/216 source proposals still had zero effect. Table-only transfer showed a
small positive mean and inconsistent source-level outcomes. No gap above is
closed by that result; fresh replication and tests of context-dependent effects
remain open. Its independent audit reconstructs all 396 attempted edits rather
than trusting a final table or a valid journal hash alone.

V5 replication: six fresh sources and a new 256-task final bank did not reproduce
v4's positive mean advantage. The declared screen failed, with g6 below empty,
g3 and random on average. Selection itself is now traceable and independently
reconstructed, but the improvement mechanism remains unresolved. The next test
targets source-only prediction of task/parent-dependent edit effects rather than
assuming that additional trials of the same unconditional table suffice.

V6 completed that diagnostic using nested whole-source folds. Context improved
MSE slightly but tied parent-only ranking utility and beat unconditional means
in only 1/9 sources. The predictor failed its advancement screen and remains
offline. Logged predictions and independently reconstructed fits now make the
prediction-to-selection gap measurable. A fresh test of richer verified edits
is next; no application-domain capability or recursive improvement is established.

V7 completed the fragment-proposer test with inherited knowledge kept outside
the identical initial solver. Memories grew, but none of 293 tested additions
changed verified correctness. All memory arms tied empty/scrambled/frozen;
the numerical control had a small heterogeneous advantage. Provenance and costs
are auditable, but the improvement mechanism still fails its screen. A corrected
state-reopening kernel fixed a real cost issue without changing the recorded
source outcomes. Full evidence: `library-results-2026-09-16.md`.

The exhaustive source follow-up found no useful single addition among all 60
compatible remembered fragments, ruling out ranking alone for that fixed set.
A separate filter repair restored visible reachability for 112/576 source tasks:
first-choice correctness 357 -> 401 and coverage@64 398 -> 458. It also caused
21 first-choice regressions and increased primitive charges 63.56%. Independent
audit reexecuted 1,152 searches. This narrows the amplifier failure mechanism;
it does not establish autonomous improvement, neural transfer, equal-compute
advantage or mission-domain usefulness. Next: fresh cost-controlled validation,
then verified-frontier distillation. See `search-diagnostic-results-2026-09-16.md`.

V8 prospectively replicated the filter benefit on 576 new tasks: +7.81 points
first-choice correctness and +11.11 points coverage@64 at ceiling 128, with
joint positive differences in five of six groups. Audit passed 4,608 reexecuted
searches. All 62 gained first choices used a program outside the old filtered
pool; 13/17 regressed tasks' old correct programs reappeared at budget 512.
This supports the representation/search-budget diagnosis. Improved neural
coverage, autonomous improver quality, inheritance and mission-domain transfer
remain open. See `search-validation-results-2026-09-16.md`.


Descendant-credit diagnostic: fresh V5 audit plus source/transfer reconstruction
found only 5/72 source entries with nonzero descendant gain sums. The descendant
score term changed two of 288 recorded adaptive transfer choices under fixed
historical draws/prefixes; this is not a policy-level counterfactual. Source
credits also reuse later observations across ancestor occurrences. This narrows
what the inherited table currently measures and motivates a separate paired-
branch credit test. See `analysis/descendant-credit-20260916.md` and
`NEXT-IMPROVER-CREDIT-STUDY.md`. No additional RSI criterion is satisfied.
