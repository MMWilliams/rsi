# V43 bounded operator invention

Status: audited attribution result. V43 added visible-only run-boundary operators (`PUNCT_RUN`, `SPACE_RUN`, `ALNUM_RUN`, `NONSPACE_RUN`, and observed literal separators) to the fixed DSL search, then swept invention cost and search width.

| Seed 2026091888 | 12/24 | 12/24 | 18/24 | 18/24 |

The first run initially appeared to show 12→18, but a paired width-3 replay on the same frozen bank reached 18/24 without invented operators. The second sealed run included the width-3 control directly and reproduced the tie. Thus the apparent gain was search-width expansion, not operator invention. The invented positional language produced no independent fresh-task capability gain.

The two sealed V43 runs audited 576 and 648 evaluation rows respectively. This is a useful negative result: expanding a researcher-bounded hypothesis metalanguage does not automatically create transferable new capability when the task distribution is already generated by the original DSL.
